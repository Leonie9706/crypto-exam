# 密码竞赛刷题 · 2026 年江苏省密码行业职业技能竞赛

把《附件3：2026年江苏省密码行业职业技能竞赛题库》做成了可以直接刷的网页程序：**理论题 1049 道（单选 492 · 多选 355 · 判断 172 · 填空 30）+ 实操题 12 道**，每一题都配「为什么错」的解析与依据。

**在线刷题（电脑/手机浏览器都能用，无需安装）：**
👉 https://你的用户名.github.io/密码仓库名/

---

## 功能

| 模块 | 说明 |
| --- | --- |
| **刷题** | 按章节 / 题型练习。单选、判断点选项即判分；多选选完点「提交答案」；填空输入后回车。做错立刻显示解析 |
| **模拟考试** | 默认 **80 题（单选 40 + 多选 20 + 判断 20）、60 分钟、满分 100 分**，题量与时长可改。交卷后统一评分并逐题解析，错题自动进错题本；中途关页面可继续上次未完成的考试 |
| **错题本** | 做错的题自动收录，显示错了几次，可重做 / 看解析 / 移除 / 导出清单 |
| **收藏** | 标记需要反复看的题，支持只练收藏题 |
| **实操题** | 第三部分 12 道 CTF 风格题（RSA 攻击、逆向、流量分析、编码转换等），含题干、思路、参考脚本与 flag |
| **统计** | 分章节掌握情况、考试记录，支持导出 / 导入学习记录（JSON） |

每道题做错都会显示：**为什么选它 → 其他选项为什么不对 → 解析 → 法律 / 标准依据 → 一句话考点**。

**快捷键**：`A`~`D` 选选项，`Enter` 提交 / 下一题，`←` `→` 翻题，`F` 收藏。

**多选题给分**：默认「少选按比例给分、错选不得分」，可在设置里切换为严格判分。

1. **题型与答案不一致（3 处）**：例如「密码前沿技术」第 4 题题干问「以下哪些」，却被排在该节的单选区、答案给了 ABC；第 8 题相反。程序在题目下方标注，不擅自改答案。
2. **排版粘连（1 处）**：「其他政策法规条例」第 2、3 题的题号与原卷配对项序号混排，已按原页图片校正题面。
3. **实操题 1** 的 `ee` 参数在原卷分页处丢字，n / hint / ct 已完整提取并验证，脚本里把 `ee` 留成输入。
4. **实操题 12** 原版脚本用 `while True`，参数抄不全会死循环，已加循环上限。

已实际复算验证的实操题：第 1、2、6、11、12 题跑通并复现原卷 flag；第 7 题前两步解码链（摩斯 → 8 栏栅栏）复现一致。
